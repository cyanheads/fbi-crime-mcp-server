# 0.1.7 — 2026-08-21

## Added

- **Plugin marketplace manifests** (`.claude-plugin/`, `.codex-plugin/`) and **community health files** — `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `LICENSE`, `.gitattributes` — scaffolded from the framework templates; `.github/FUNDING.yml` trimmed to active entries.
- **Supply-chain install guard** ([core 0.10.13](https://github.com/cyanheads/mcp-ts-core/blob/main/changelog/0.10.x/0.10.13.md)) — `bunfig.toml` holds freshly published packages for 3 days (`minimumReleaseAge`; the framework is excluded so core adopts same-day) and runs the Socket scanner on every install.
- **devcheck guards re-synced** from the framework: floating dependency specifiers (`latest`/`*`/dist-tags) rejected in `package.json` + `bun.lock` ([core #246](https://github.com/cyanheads/mcp-ts-core/issues/246)); plugin-manifest identity/install lint ([core #240](https://github.com/cyanheads/mcp-ts-core/issues/240)); the MCPB bundle strips platform-specific `@duckdb` native bindings so it stays portable under registry size caps ([core #274](https://github.com/cyanheads/mcp-ts-core/issues/274)).
- **Dockerfile** — base image `oven/bun:1.3` → `1.4.0`, build stage pinned to `$BUILDPLATFORM` so multi-arch builds compile natively, BuildKit cache mounts on every install, production installs add `--omit=peer` to skip optional peer tiers, OCI `source` label.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.8` → `^0.12.3`** — the MCP SDK v2 lineage ([core 0.12.0](https://github.com/cyanheads/mcp-ts-core/blob/main/changelog/0.12.x/0.12.0.md)): `@modelcontextprotocol/server` 2.0.0, protocol revision 2026-07-28 served alongside the 2025 era on every HTTP endpoint, 2020-12 JSON Schema advertisements, the error envelope declared in `outputSchema`, and input-validation failures rendered as flat `path: message` sentences.
- **Tool inputs are strict** ([core #232](https://github.com/cyanheads/mcp-ts-core/issues/232)) — undeclared root-level argument keys are rejected by name (`additionalProperties: false`) instead of silently stripped.
- **`FbiApiService` routes through the framework `fetchWithTimeout`** — the hand-rolled `AbortController` timer is gone; request timeouts classify as `Timeout` (-32004) instead of `ServiceUnavailable`, the deadline bounds the response body and not just the headers ([core #341](https://github.com/cyanheads/mcp-ts-core/issues/341)), and `withRetry` honors upstream `Retry-After` delays ([core #285](https://github.com/cyanheads/mcp-ts-core/issues/285)).
- **Throw-only handlers drop `async`** — decommissioned-endpoint tools and resources declare synchronous handlers; the summarized getters follow.
- **TypeScript `^6.0.3` → `^7.0.2`** drives typecheck and the build ([core 0.11.0](https://github.com/cyanheads/mcp-ts-core/blob/main/changelog/0.11.x/0.11.0.md)).
- **npm metadata** — author normalized to `Casey Hand <casey@caseyjhand.com> (https://caseyjhand.com)`; the published tarball ships `changelog/` and `AGENTS.md`.
