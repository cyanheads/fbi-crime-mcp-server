# 0.1.4 — 2026-06-12

## Added

- `name`/`title` (`fbi-crime-mcp-server`) passed explicitly to `createApp()` — pins the display identity instead of falling back to the npm-scoped package name.
- `FBI_API_KEY` declared in `manifest.json` (`mcp_config.env` + `user_config.fbi_api_key`, required + sensitive) and in both `server.json` package entries (`environmentVariables`) so bundle install and registry discovery prompt for the key.
- `manifest.json` metadata: `description`, `author`, `repository`, `homepage`, `license` (previously empty).
- `Dockerfile`: `org.opencontainers.image.version` OCI label fed by the `APP_VERSION` build arg, and a `HEALTHCHECK` polling `/healthz`.
- `CITATION.cff` for citation metadata.
- `format:unsafe` script (`biome check --write --unsafe`); `release:github` script (`scripts/release-github.ts`).

## Changed

- `fbi_get_crime_estimates`, `fbi_get_agency_offenses`, `fbi_get_leoka`: `scope_param_missing` / `month_required` error codes `InvalidParams` → `ValidationError`.
- `format` script no longer applies Biome unsafe fixes (`biome check --write`); unsafe autofixes move to `format:unsafe`.
- `bundle` script runs `scripts/clean-mcpb.ts` after pack to prune dev deps and strip dependency-shipped agent docs from the `.mcpb`.
- README MCP client config key `fbi-crime` → `fbi-crime-mcp-server`.
- `.mcpbignore` patterns root-anchored (leading `/`); added `/.agents/` and `/skills/`.
- Synced vendored framework skills and build scripts to mcp-ts-core 0.10; agent-protocol docs (`CLAUDE.md`) updated for the removed `ctx.sample` and the `z.stringbool()` env-flag rule.
