# 0.1.8 — 2026-09-21

## Changed

- **`fbi_get_crime_estimates` / `fbi_get_agency_offenses`** report the agency's own `rate_per_100k` and `clearance_rate_per_100k` at `scope: "agency"` instead of its state's — the CDE `offenses.rates` map lists the state and nation ahead of the agency; the handlers now select the entity `actuals` already scopes to ([#10](https://github.com/cyanheads/fbi-crime-mcp-server/issues/10))
- HTTP session mode is `stateless` however the server is launched: `createApp` declares it and `.env.example` sets it, matching the Docker image. An explicit `MCP_SESSION_MODE` still overrides the declaration; unset, a source or `npx` HTTP run previously resolved `auto` → `stateful` ([#9](https://github.com/cyanheads/fbi-crime-mcp-server/issues/9))
- The nine decommissioned tools now throw via `ctx.fail`, carrying `data.reason: "endpoint_decommissioned"` and their declared recovery hint on the wire — e.g. `fbi_get_arson` points to `fbi_get_crime_estimates` with `offense="arson"`. Error code and message text are unchanged
- Codex plugin installs forward `FBI_API_KEY` via `env_vars`, where the whitelisted stdio environment dropped it before; the Claude Code plugin now prompts for the key through a `userConfig` option

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.12.3 → ^0.13.6: argument rejections carry `structuredContent.error` (`-32602`, `reason: invalid_arguments`) with a synthesized `Recovery:` hint ([cyanheads/mcp-ts-core#377](https://github.com/cyanheads/mcp-ts-core/issues/377), [cyanheads/mcp-ts-core#445](https://github.com/cyanheads/mcp-ts-core/issues/445)); tool error text closes with `(reason <reason>)` when a reason is set ([cyanheads/mcp-ts-core#458](https://github.com/cyanheads/mcp-ts-core/issues/458)); a case-variant argument key that matches exactly one declared key now resolves to it ([cyanheads/mcp-ts-core#452](https://github.com/cyanheads/mcp-ts-core/issues/452)); an upstream 500 classifies as `ServiceUnavailable` and retries with backoff instead of failing immediately as `InternalError` ([cyanheads/mcp-ts-core#323](https://github.com/cyanheads/mcp-ts-core/issues/323)); `/.well-known/mcp.json` publishes the resolved session mode under `_meta["io.github.cyanheads.mcp-ts-core/sessionMode"]` ([cyanheads/mcp-ts-core#387](https://github.com/cyanheads/mcp-ts-core/issues/387)); `SIGTERM`/`SIGINT` now end the process explicitly once shutdown settles ([cyanheads/mcp-ts-core#435](https://github.com/cyanheads/mcp-ts-core/issues/435)); Bun engines floor `>=1.3.0` → `>=1.4.0`, matching the framework's floor
- `zod` ^4.4.3 → ^4.6.5 — nullable number fields in the `fbi_get_crime_estimates` / `fbi_get_agency_offenses` `outputSchema` now render as `type: ["number", "null"]` instead of an equivalent `anyOf`; semantically identical
- `@biomejs/biome` ^2.5.9 → ^2.5.14, `@types/node` ^26.2.0 → ^26.6.2, `ignore` ^7.0.6 → ^7.0.9, `tsc-alias` ^1.9.2 → ^1.9.5, `vitest` ^4.1.11 → ^5.0.1
