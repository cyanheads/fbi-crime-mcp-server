# 0.3.0 — 2026-10-13

## Added

- **Summarized coverage** adds `entity_name`, optional `max_data_date`, and monthly `population`, `participated_population`, and `population_coverage_percent` on both output surfaces. Values use the exact provider entity/month; missing coverage stays null and is never inferred or borrowed. ([#19](https://github.com/cyanheads/fbi-crime-mcp-server/issues/19))

## Changed

- **Selectors** reject identifiers irrelevant to the selected scope and `month` on YTD LEOKA before fetching. Remove irrelevant IDs/month from existing calls; matching state/ORI pairs are rejected too. ([#16](https://github.com/cyanheads/fbi-crime-mcp-server/issues/16))
- **Registry launch metadata** uses `npx` without npm-script arguments and fixes the HTTP entry's `MCP_TRANSPORT_TYPE` to `http`; the hosted endpoint is documented.
- **Maintenance** syncs framework guidance and packaging checks, uses Bun 1.4.3 container stages, prunes unused musl packages from glibc images, aligns CodeQL categories, and logs upstream paths without hosts.

## Removed

- **`fbi_get_agency_offenses`** is removed. Use `fbi_get_crime_estimates` with the same applicable scope, offense, identifier and dates. ([#7](https://github.com/cyanheads/fbi-crime-mcp-server/issues/7))
- **Retired MCP contracts** disable nine UCR tools and unregister both resource templates. Discovery exposes two callable tools and no resources; the HTTP operator page retains disabled reasons. ([#14](https://github.com/cyanheads/fbi-crime-mcp-server/issues/14))

## Fixed

- **Summarized date ranges** reject reversed complete year/month endpoints before fetching, with date correction guidance. Equal and forward ranges remain valid. ([#15](https://github.com/cyanheads/fbi-crime-mcp-server/issues/15))
- **State/ORI identifiers** accept ASCII casing equivalents, normalize them to uppercase, and reject malformed grammar locally. Unknown well-formed identifiers retain `no_data` with identifier-first recovery. ([#17](https://github.com/cyanheads/fbi-crime-mcp-server/issues/17))
- **Framework representation repairs** accept string-valued `from_year`, string-valued LEOKA `month`, and null optional `state_abbr` on national calls through the adopted framework.
