# 0.2.0 — 2026-09-30

## Added

- **`fbi_get_leoka`** exposes all thirteen circumstance, demographic, and timeline fields in structured output and text, retaining comparison years, unknown categories, empty groups, null counts, and zeros ([#6](https://github.com/cyanheads/fbi-crime-mcp-server/issues/6)).

## Changed

- **LEOKA totals** replace the four `_felonious`/`_accidental` aliases with their original `_dod`/`_doi` keys, preserving values. Both periods label the upstream YTD block separately from classified trends and monthly breakdowns ([#8](https://github.com/cyanheads/fbi-crime-mcp-server/issues/8)).
- **Error recovery** uses the framework's automatic contract forwarding across all twelve tools.
- **Docker** cross-installs production dependencies on the build platform and includes the framework's optional OpenTelemetry log-export peers; `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` is documented separately from the trace/metric base URL.
- **Packaging and tooling** exclude MCPB bundles from npm and local notes/logs from MCPB; synchronize framework skills, project guidance, and checks for definition imports, package versions, Docker build platforms, and tag annotations.

## Fixed

- **Absent CDE data** returns `no_data` with declared recovery for null/empty LEOKA envelopes and missing scoped summarized actuals; malformed records retain serialization errors and valid entity-matched rates remain intact ([#11](https://github.com/cyanheads/fbi-crime-mcp-server/issues/11)).
- **Capability documentation** reflects active CDE endpoints, accepted offense values, raw totals migration, and the full LEOKA output.
